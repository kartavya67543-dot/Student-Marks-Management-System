# 📊 Student Marks Management System

A beginner Excel project that automatically calculates student results.

## Features

- Calculates Total Marks
- Calculates Percentage
- Assigns Grades Automatically
- Displays Pass/Fail Status
- Conditional Formatting for Grades
- Excel Table with Filters

## Skills Used

- SUM()
- IF()
- AND()
- Nested IF
- Conditional Formatting
- Excel Tables
